# 规则知识目录

本目录将保存 BotC-AI 可检索的版本化规则知识与生成清单。目前只建立目录约定，不包含抓取内容。

## 计划结构

```text
knowledge/
├── sources/       # 来源清单、抓取时间、页面版本、许可证与内容哈希
├── official/      # 官方规则书、Wiki、角色 Almanac、相克与勘误的规范化内容
├── localized/     # 中文等本地化辅助资料，不覆盖官方规则结论
├── index/         # 浏览器可加载的版本化检索索引
└── reports/       # 同步、解析、重复、缺失与质量报告
```

实际生成目录和大体积索引是否提交到 Git，必须在 Wiki 同步需求中根据许可证、体积和更新策略确认。

## 来源优先级

1. 当前采用版本的官方规则书。
2. 官方 Blood on the Clocktower Wiki 与角色 Almanac。
3. 官方相克规则、勘误和发布说明。
4. 已在具体需求中确认的说书人裁量策略。
5. 中文社区 Wiki 等本地化辅助材料。

每条检索结果必须携带来源 URL、页面标题、版本或抓取时间和匹配片段。发生冲突时，辅助材料不能覆盖官方来源。

## 实现约束

- 只允许从配置的域名和入口同步，遵守来源站点许可与合理抓取频率。
- 使用 HTML 解析器提取正文，不直接复制相邻实验项目的正则抓取代码。
- 网页内容视为不可信数据，清除脚本与危险标记，并防止其文本提升 Agent 工具权限。
- 抓取、清洗、切分和索引均需固定样本测试与失败报告。
- 对局运行时读取本地知识包，不在规则关键路径临时抓取网页。
