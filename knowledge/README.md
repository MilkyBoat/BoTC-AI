# 规则知识目录

本目录保存 BotC-AI 可检索的版本化规则知识与生成清单。目前已冻结 M1 规则范围元数据，并已实现固定修订 Wiki 同步与 DOM 清洗工具；官方规则正文仍未提交。

## 计划结构

```text
knowledge/
├── sources/       # 来源清单、抓取时间、页面版本、许可证与内容哈希
├── official/zh-CN/ # 中文官方规则、Wiki、角色说明、相克与勘误的规范化内容
├── official/en/   # 中文资料缺失时使用的英文官方来源原文
├── translated/zh-CN/ # 英文缺失补充对应的中文翻译、复核状态与来源映射
├── rulesets/      # 规则范围 Schema、版本化范围清单与完整性标识
├── index/         # 浏览器可加载的版本化检索索引
└── reports/       # 同步、解析、重复、缺失与质量报告
```

`sources/` 当前提交同步配置以及配置、逐页元数据、成功清单和报告的 Draft-07 Schema，不提交现场抓取结果。实际生成正文、大体积索引和图片是否进入 Git 或发布，必须在后续需求中根据许可证、体积和更新策略确认。

## Wiki 同步工具

默认使用 M1-R1 现有 39 个固定修订作为输入契约，输出到被 Git 忽略的 `.work/m2-r2-wiki-sync/output/`：

```bash
npm run knowledge:sync
```

现场排查单页时可使用稳定来源 ID；部分输出中，清单内但本次未生成的页面会保留固定在线修订，不产生断裂本地链接：

```bash
npm run knowledge:sync -- --only zh-wiki-glossary
```

同步器同时校验 HTML 页面身份、MediaWiki API 修订/时间与原始 Wikitext SHA-256。结果目录包含 `official/<language>/` Markdown、`sources/` 逐页元数据与成功清单、`reports/wiki-sync.json` 和中文报告。正文新链接只进入候选报告；M2-R1 确认前不得据此自动扩充官方来源。输出目录必须位于仓库中，并通过所有权标记防止覆盖其他文件；已有成功输出时，失败诊断写入同名 `.failed` 旁路目录。

## 来源优先级

1. 当前采用版本的集石《染·钟楼谜团》中文官方规则与钟楼百科。
2. 中文官方角色说明、相克规则、勘误和发布说明。
3. 中文资料缺失时使用的英文官方规则、Wiki 与角色说明；进入产品前必须翻译为中文并保留双向来源记录。
4. 已在具体需求中确认的说书人裁量策略。
5. 其他社区资料只可帮助发现待核对问题，不能进入规范规则包。

每条检索结果必须携带来源 URL、页面标题、页面修订或抓取时间、内容哈希和匹配片段。英文补充还必须携带中文翻译版本和复核状态。中英文官方资料发生语义冲突时无条件采用中文官方结论，英文差异只进入同步报告，不允许同步工具静默覆盖。

## 实现约束

- 只允许从配置的域名和入口同步，遵守来源站点许可与合理抓取频率。
- 使用 HTML 解析器提取正文，不直接复制相邻实验项目的正则抓取代码。
- 网页内容视为不可信数据，清除脚本与危险标记，并防止其文本提升 Agent 工具权限。
- 抓取、清洗、切分和索引均需固定样本测试与失败报告。
- 对局运行时读取本地知识包，不在规则关键路径临时抓取网页。
- 首期索引、检索结果和 Agent 可见规则内容均使用中文；英文原文只作为可追溯来源保存，不直接构成英文产品环境。
- `rulesets/` 中的 `0.2.0` 范围清单保存规则集身份、中文显示名称、稳定 ASCII ID、支持状态、108 个规范概念、三个官方概念目录、当前 110 个角色的能力类别关联和固定来源指针，不复制规则正文。
- 80 个术语、31 个能力类别和 7 个重要规则主题通过目录索引保持各自官方顺序；跨页重名内容复用同一规范概念，并保留多来源引用和中文别名。
- 概念的实现责任只能是内核规则、说书人裁量或参考概念。参考概念不直接进入规则执行；中文官方类别页未列出的范围内角色保留空关联，禁止推测补全。
- 来源正文哈希使用固定 MediaWiki 修订的原始 Wikitext 计算，范围清单自身使用 `sorted-json-v1` 规范化后计算 SHA-256。
- Wiki 同步命令只接受显式固定来源；逐页元数据同时记录 Wikitext、HTML 与 Markdown 哈希、清洗统计和 `untrusted-external-content` 标记。
- 同步请求使用显式 `ClocktowerKnowledgeSync` User-Agent、串行一秒最小间隔、超时、响应体上限和有限退避重试；自动测试注入假 HTTP，不访问真实站点。
- 生成 Markdown 使用稳定来源 ID 文件名，清除危险节点和属性，保留结构化正文与同源图片引用；候选、拒绝、重定向、重复和失败均进入报告。
