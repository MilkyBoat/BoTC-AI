# 魔典站点部署

## 元信息

- 状态：阻断
- 创建日期：2026-07-16
- 关联需求：[项目基线、规划与仓库初始化](2026-07-16-project-initialization.md)
- 目标托管：OpenAI Sites

## 背景与目标

用户要求把当前仓库中的 townsquare 魔典部署为可访问站点并返回链接。在首次发现 Sites 的所有部署均属于生产部署后，执行因当前会话生效的“任何情况下禁止直接修改线上/生产环境”约束暂停。用户随后明确声明本仓库希望豁免该限制，并明确同意自动完成部署。

产品目标没有歧义：发布当前经过验证的静态魔典，得到可访问 URL，并把 URL 与对应源码提交写回本文。

## 已确认需求

- 发布内容为当前仓库构建出的魔典，不新建独立落地页，不改变游戏交互。
- 使用当前已接入的 Sites 构建与托管能力。
- 用户已经明确同意本仓库执行站点创建、版本保存和部署操作。
- 发布前使用 `npm run build` 生成静态产物，页面标题和站点元数据使用 BotC-AI 品牌，同时保留上游作者与许可证归属。
- 不使用或修改 `clocktower.online` 域名、上游 GitHub Pages、上游 WebSocket 服务及任何既有生产资源。
- 部署结果必须与本地初始化提交对应，不能发布未提交或未经验证的源码状态。

## 范围

- 验证生产构建与静态入口。
- 创建或复用 BotC-AI 的 Sites 项目。
- 保存与已提交源码一致的站点版本。
- 在允许的访问模式下部署并轮询到成功。
- 验证部署 URL 可访问并返回魔典入口。
- 把部署 URL、访问模式、部署时间和对应提交写回本文，并在最终交付中返回链接。

## 非范围

- 不部署 WebSocket 中继服务。
- 不把 AI、LLM Provider 或尚未实现的规划能力描述为已上线。
- 不配置自定义域名。
- 不修改 GitHub、上游仓库或现有线上站点。
- 不在部署时接入真实 LLM Key、玩家数据或生产对局数据。

## 访问与安全

优先使用 Sites 私有部署能力，避免在项目仅有上游基线时形成公开生产承诺。若当前托管只支持公开部署，必须在调用公开部署前重新确认访问范围。

本次发布只包含 GPL-3.0 上游源码、静态素材和本项目规划文档相关元数据。模型密钥、证书、`.env`、本地日志、`node_modules` 和构建临时文件不得进入站点版本。

## 验收标准

- `npm run build` 成功，`dist/index.html`、`dist/js` 和 `dist/css` 存在。
- 部署版本绑定到已本地提交且作者邮箱为 `qq.com` 的源码提交。
- Sites 返回最终状态 `succeeded` 和 HTTPS URL。
- URL 返回成功状态并加载 BotC-AI 魔典入口与静态资源。
- 本文填写实际部署结果，根 README 提供站点入口。

## 当前阻断

用户的豁免意图和发布授权已经完整记录。要完成剩余步骤，需要在新的受控执行环境中由上级规则正式移除该禁止项；届时应复用本需求文档，而不是重新猜测范围。
