# TownSquare 智能主持人：整体架构设计

## 1. 范围与目标

- 合并：将 `townsquare/` 整体并入当前项目，完成所有改造后删除 `townsquare/` 目录
- AI 位置：AI 作为主持人网页端内置模块运行，不使用任何网络桥接
- 运行模式：本期仅全自动模式，后续引入半自动与人类监督
- 配置：主持人端可输入 API_KEY 等配置并存入 localStorage，调试阶段允许从 server .env 注入默认值

## 2. 合并后的目录结构与模块边界

### 2.1 目录迁移建议

- `townsquare/src` → `src/web/townsquare`
- `townsquare/public` → `src/web/public`
- `townsquare/server` → `src/server/live-session`
- `townsquare/package.json` 的依赖合并到根目录 `package.json`

### 2.2 模块分层

- **UI 与状态层（Web）**
  - `src/web/townsquare`：TownSquare Vue App（组件 + Vuex）
  - `src/web/townsquare/store/socket.js`：主持人/玩家 WebSocket 同步
  - `src/web/townsquare/store/modules/*`：session、players 等状态模块

- **实时会话层（Server）**
  - `src/server/live-session/index.js`：WebSocket relay（迁移自 `townsquare/server/index.js`）
  - 职责：转发消息、保持低限度的连接治理与限制

- **AI 内置模块层（Web）**
  - `src/web/agent`：浏览器端 Agent 主入口
  - `src/web/agent/adapters/townsquareAdapter`：TownSquare 状态 ↔ AgentState 映射
  - `src/web/agent/actions`：Action 到 Vuex mutation 的执行器

- **配置与安全层（Web）**
  - `src/web/config`：配置管理与 localStorage 读写
  - `src/web/config/ConfigPanel.vue`：主持人端可见的配置表单
  - `src/web/config/defaults`：开发调试注入的 .env 默认值

## 3. 核心交互与数据流

### 3.1 主持人动作 → 玩家同步

- 主持人 UI 修改 Vuex
- `store/socket.js` 将变更通过 WebSocket 同步给玩家

### 3.2 AI 动作 → 玩家同步

- Agent 在浏览器端生成 Action
- Action 映射为 Vuex mutation 并提交
- socket layer 继续广播给玩家

### 3.3 玩家交互 → 主持人同步

- 玩家客户端发送 `claim`、`vote`、`chat` 等消息
- 主持人端 socket layer 接收并更新 Vuex

## 4. 配置输入与默认值策略

- **优先级**：localStorage > .env 注入默认值 > 空值
- **注入方式（调试）**：server 启动时将 .env 映射为 `window.__APP_CONFIG__` 或构建时常量
- **主持人配置表单**：
  - API_KEY / Provider / Model / Temperature / MaxTokens 等
  - 可随时修改，立即影响 Agent 行为

## 5. 人类监督与半自动模式的预留口子

### 5.1 监督者手动更改记录

- 人类在主持人端对状态的手动调整，记录为 `supervisor_action`
- 包含：变更对象、前后差异、时间戳、备注

### 5.2 监督者上下文注入

- Agent 每轮推理将最新 `supervisor_action` 作为额外上下文
- 以“工具调用回放”形式写入，确保 AI 理解人类介入

## 6. 关键模块职责清单

- `src/web/townsquare/store/socket.js`
  - 职责：主持人/玩家同步通道
  - 承载：`gs`、`player`、`vote`、`chat` 等消息处理

- `src/web/agent`
  - 职责：AI 推理与 Action 生成
  - 输入：TownSquare store 快照
  - 输出：Action + 解释文本

- `src/web/agent/adapters/townsquareAdapter`
  - 职责：TownSquare ↔ AgentState 映射、Action 映射

- `src/web/config`
  - 职责：配置读写、localStorage 持久化、默认值合并

- `src/server/live-session`
  - 职责：WebSocket relay 转发与限制
