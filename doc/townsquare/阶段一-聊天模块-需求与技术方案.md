# 阶段一：魔典聊天模块（需求与技术方案）

## 1. 需求描述

### 1.1 目标

- 在 TownSquare 的“魔典”界面内新增聊天模块
- 支持主持人对所有玩家广播消息
- 支持主持人与单个玩家 1 对 1 私聊
- 玩家侧可查看主持人消息，并可向主持人发起私聊
- 页面左侧放置一个可收起的常驻聊天模块，展示聊天记录与消息输入
- 为后续 AI Agent 整合预留入口，提供公开函数允许 AI 发送与接收消息

### 1.2 不做的事项

- 不引入 AI 能力
- 不改变现有 WebSocket relay 的职责

## 2. 技术方案（细化到模块）

### 2.1 协议扩展（WebSocket）

新增 `chat` command，复用 relay 的广播与 `direct` 拆包能力：

- 广播：`["chat", { from: "host"|"player", text, ts, scope: "broadcast" }]`
- 私聊：
  - Host → Player：`["direct", { [playerId]: ["chat", { from:"host", text, ts, scope:"direct" }] }]`
  - Player → Host：`["direct", { host: ["chat", { from:"player", text, ts, scope:"direct", fromPlayerId }] }]`

### 2.2 前端模块改动

- `src/web/townsquare/store/socket.js`（迁移自 `townsquare/src/store/socket.js`）
  - 新增 `chat` 处理分支：Host/Player 都应消费
  - 新增发送方法：
    - `sendChatBroadcast(text)`
    - `sendChatDirect(playerId, text)`

- `src/web/townsquare/store/modules/chat.js`（新增）
  - 存储消息历史（按 session + playerId 分组）
  - 未读计数、最近会话列表

- `src/web/townsquare/components/ChatPanel.vue`（新增）
  - 进入对局后才展示，未进入房间时隐藏
  - 左侧常驻可收起面板
  - 聊天记录每条一行，展示格式：`【X】message content`（若有名称则显示 `X.name`）
  - 与 bluffs 面板保持一致的外观、展开/收起按钮位置与动画风格
  - 聊天面板收起时宽度同步收缩，仅保留能完整显示标题文字的最小标题栏；展开时根据 bluffs 面板状态动态收缩底边，避让左下角展示区
  - Host 视角：
    - 输入框左侧提供人员选择框，下拉选择：全体或指定玩家私聊
    - 支持在输入框内用 `@` 指定对象：`@all` 或 `@3`，后接消息内容
  - Player 视角：
    - 不展示人员选择框
    - 仅允许与主持人私聊，不支持广播

- `src/web/townsquare/components/TownInfo.vue`
  - 将中央的剧本名称、玩家总数与阵营数量移动到左上角
  - 左上角仅保留名称与人数信息，剧本图片仍保留在原画面中心区域
  - 左上角信息区不使用背景与边框，直接叠加在画面上
  - 人数信息按“总人数/存活数/投票数/阵营数”分行展示，每类信息保持单行，允许后续新增阵营类型
  - 采用紧凑面板布局，避免与聊天面板重叠

- `src/web/townsquare/components/Menu.vue`
  - Host 菜单中增加“聊天”入口，控制左侧面板展开/收起

- `src/web/townsquare/chat/api.js`（新增）
  - 对外公开函数：
    - `sendChat({ target, text })`
    - `subscribeChat(handler)`
  - 供后续 AI Agent 调用

### 2.3 权限与安全

- Host 端仅处理 `chat` 相关消息，不允许通过聊天 payload 修改其他状态
- 对玩家发来的 direct 消息仅接受 `chat` 子命令

### 2.4 交互与快捷键

- 在聊天输入框内输入时，不触发全局快捷键
- 通过输入框聚焦状态屏蔽全局按键监听
- 聊天面板与 bluffs 面板共享展开/收起状态风格，但各自独立控制
- bluffs 展开时，聊天面板自动上缩，保证左下角 bluffs 展示区完整可见
- bluffs 收起时，聊天面板仍需为其保留标题栏区域，避免遮挡

## 3. 验收标准

- Host 可广播消息给全部玩家
- Host 可向指定 playerId 私聊
- 玩家可回复 host
- 消息历史在会话内持久可见（刷新后可选保留或清空）
- Host 可通过下拉或 `@` 指定发送对象
- Player 侧不显示人员选择，仅与 Host 私聊
- 未进入房间时不显示聊天面板
- 左上角展示剧本与人数信息，且不与聊天面板重叠
- 剧本图片保持在画面中心，不进入左上角信息面板
- 左上角信息区不包含背景和边框
- bluffs 展开时聊天面板自动避让，不遮挡左下角 bluffs 区域
- bluffs 收起时聊天面板也不遮挡其收起后的标题栏
- 聊天面板收起后宽度收缩到标题栏最小可读尺寸
